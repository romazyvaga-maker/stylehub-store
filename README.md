# StyleHub — интернет-магазин одежды

## Что нужно
- Node.js 20 или новее: https://nodejs.org/
- Любой редактор кода, например Visual Studio Code: https://code.visualstudio.com/
- Браузер.

## Запуск на компьютере
1. Распакуй архив в отдельную папку.
2. Установи Node.js LTS и перезапусти терминал/VS Code.
3. Открой терминал в папке проекта.
4. Выполни `npm install`.
5. Скопируй `.env.example` в файл `.env`.
6. В `.env` задай длинный случайный `SESSION_SECRET`, а также собственные `ADMIN_EMAIL` и `ADMIN_PASSWORD`.
7. Выполни `npm start`.
8. Открой http://localhost:3000

База данных SQLite создаётся автоматически в `data/store.sqlite`. При первом запуске появятся демонстрационные товары и администратор, если его email ещё не существует.

## Админ-панель
Войди через кнопку аккаунта с данными `ADMIN_EMAIL` и `ADMIN_PASSWORD` из `.env`. Через панель можно добавлять/редактировать/удалять товары, загружать фото и менять статусы заказов.

## Как проверить
- Открой каталог и карточку товара.
- Добавь товар в корзину, поменяй количество.
- Зарегистрируй тестовый аккаунт.
- Оформи тестовый заказ.
- Выйди и войди под администратором, проверь товары и заказы.
- Не публикуй сайт с демонстрационным паролем.

## Публикация в интернете
Для запуска сервера нужен хостинг, который поддерживает Node.js и постоянное хранение файлов. Обычный статический хостинг не подходит. Подойдёт небольшой VPS или Node.js-хостинг с постоянным диском.
1. Загрузи проект на хостинг (обычно Git через GitHub или панель хостинга).
2. Установи зависимости командой `npm install`.
3. Создай переменные окружения `SESSION_SECRET`, `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `NODE_ENV=production`.
4. Запусти `npm start` через менеджер процессов хостинга.
5. Подключи домен по инструкции хостинга и включи HTTPS.
6. Убедись, что папки `data/` и `uploads/` находятся на постоянном диске и доступны приложению для записи.
7. Проверь регистрацию, вход, загрузку фото и создание заказа уже на домене.

## Важно перед реальным запуском
Это рабочий учебный стартовый проект, но не готовая платформа для крупных продаж. Перед реальным использованием добавь ограничение частоты запросов, защиту CSRF, резервное копирование базы, политику конфиденциальности и условия возврата/доставки. Настрой HTTPS и сильные секреты. Сейчас заказ сохраняется в базе, но онлайн-оплата, интеграция с перевозчиком и автоматические email/SMS не подключены. Изображения в стартовых товарах загружаются с Unsplash; для своего магазина замени их своими фотографиями. Цены в гривнах.
